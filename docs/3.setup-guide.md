# Local Development & Setup Guide — Oneself

This guide walks through setting up the **Oneself Monorepo** on your local machine for rapid development and testing.

---

## 📋 Prerequisites

Before starting, ensure your system has the following installed:
- **Node.js:** `v20.19.0` or higher (`v24.19.0` recommended, managed via `nvm` or `fnm`)
- **pnpm:** `v12.x` (`npm install -g pnpm@latest` or `corepack enable`)
- **MongoDB:** Local MongoDB instance (`mongodb://localhost:27017`) or Docker container
- **Git**

---

## 🛠 Step 1: Install Workspace Dependencies

From the repository root:
```bash
pnpm install
```
pnpm will install and link dependencies across all projects in `apps/*` into a unified `node_modules` store with hard-links.

---

## 🔑 Step 2: Environment Configuration

Each application requires its own environment file. Copies can be created from their `.env.example` templates:

### 1. Server Environment (`apps/server/.env`)
```bash
cp apps/server/.env.example apps/server/.env
```
Key variables to verify:
```env
PORT=5000
DB_URL=mongodb://localhost:27017/oneself_dev
CLIENT_SIDE_URL=http://localhost:3000
ACCESS_TOKEN_SECRET=your_super_secret_access_key
REFRESH_TOKEN_SECRET=your_super_secret_refresh_key
```

### 2. Storefront Environment (`apps/front/.env.local`)
```bash
cp apps/front/.env.example apps/front/.env.local
```
Key variables to verify:
```env
PORT=3000
NEXT_PUBLIC_FRONT_API_BASE_URL=http://localhost:5000
```

### 3. Dashboard Environment (`apps/dashboard/.env.local`)
```bash
cp apps/dashboard/.env.example apps/dashboard/.env.local
```
Key variables to verify:
```env
PORT=3001
NEXT_PUBLIC_API_BASE_URL=http://localhost:5000
```

---

## 🚀 Step 3: Run the Development Server

### Run All Applications Simultaneously
```bash
pnpm dev
```
Turborepo will concurrently start:
- `apps/front` on [http://localhost:3000](http://localhost:3000)
- `apps/dashboard` on [http://localhost:3001](http://localhost:3001)
- `apps/server` on [http://localhost:5000](http://localhost:5000)

### Run Specific Apps
```bash
pnpm dev:front       # Only Storefront
pnpm dev:dashboard   # Only Dashboard
pnpm dev:server      # Only Express API
```

---

## 🧪 Step 4: Verification & Quality Checks

Run the full suite of quality gates from the repository root:

```bash
# Typecheck all TypeScript code
pnpm typecheck

# Lint all packages
pnpm lint

# Format code with Prettier
pnpm format
```

---

## 📦 Step 5: Database Seeding & Migrations

If initializing a fresh database, run the seed script from `apps/server`:
```bash
cd apps/server
pnpm run seed
```
To run data or image path migrations:
```bash
pnpm run migrate:data
pnpm run migrate:media
```
