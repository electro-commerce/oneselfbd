# Platform Features & Modules — Oneself

A functional overview of the core modules and capabilities implemented across the **Oneself Platform**.

---

## 🛡 1. Authentication & Role-Based Access Control (RBAC)

- **Token Strategy:** Dual-token JWT system (short-lived access tokens + rotating refresh tokens stored in HTTP-only, secure cookies).
- **Roles:**
  - `SUPER_ADMIN`: Complete system ownership, user permissions assignment, financial reports.
  - `ADMIN`: Order management, product creation, coupon creation, warranty validation.
  - `STAFF`: Order fulfillment, parcel dispatch, tracking status updates.
  - `CUSTOMER`: Account dashboard, order history, warranty claims.
- **Client Route Protection:** Redux-driven `AuthGuard` ensuring unauthenticated users cannot access administrative views.

---

## 🛒 2. Order Management & Checkout Pipeline

- **Checkout Engine:** Supports single-page fast checkout, guest ordering, and registered customer flows.
- **Fraud Prevention:** Automated integration with courier fraud detection APIs (evaluates return ratios and delivery history).
- **Coupons & Discounts:** Dynamic coupon engine supporting percentage, fixed discounts, minimum spend thresholds, and date validity checks.
- **Order Limits:** Configurable velocity limits to prevent brute-force cart exhaustion or fraudulent batch orders.
- **Invoicing:** Built-in printable invoice generator with barcode and itemized breakdown.

---

## 🏷 3. Product Catalog & Inventory

- **Dynamic Variations:** Attributes (size, color, weight) with individual stock quantities and SKU tracking.
- **Rich Media Gallery:** Touch-friendly product gallery with zoom, responsive carousel thumbnails, and video support.
- **Media Upload Manager:** Flexible storage provider support for local disk, Cloudflare R2, or Amazon S3 with auto-resizing via `sharp`.

---

## 🛡 4. Warranty Registration & Claims

- **Warranty Engine:** Automated calculation of warranty expiry based on order delivery date.
- **Customer Self-Service:** Customers can search by phone number or order number to find eligible products.
- **Claim Workflow:** Multi-step claim submission requiring video/image defect evidence, description, and status tracking (Pending ➔ Under Review ➔ Approved ➔ Repaired/Replaced).

---

## 📦 5. Courier Logistics Integration

- **Supported Partners:**
  - **Steadfast Courier:** API parcel creation, tracking webhooks, delivery verification.
  - **Pathao Courier:** Automated consignment generation and status synchronization.
  - **Redx & Paperfly:** Supported secondary courier channels.
- **Bulk Dispatch:** Admin interface for selecting multiple orders and generating consignment slips in a single click.
